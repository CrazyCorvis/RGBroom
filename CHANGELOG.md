# Изменения

## 9.1.0 — macOS

- Первая macOS-сборка для Apple Silicon, macOS 14+; среда .NET включена в приложение.
- Нативный интерфейс SwiftUI с системным оформлением macOS 27, боковой навигацией, меню, горячими клавишами, светлой/тёмной темой.
- Пять режимов на общем C#-движке: цвет, переход, цветомузыка, спектр и фон.
- ScreenCaptureKit для системного звука и выбранного дисплея; CoreBluetooth для ELK-BLEDOM и Triones.
- Wi-Fi-адаптеры Magic Home, WLED, Yeelight и Tuya LAN переиспользуются без копирования протоколов.
- Ключи Tuya защищены Keychain; настройки сохраняются в `~/Library/Application Support/RGBroom/`.
- Скрипт сборки `.app`, автоматические проверки macOS/Windows и документация по разрешениям и отличиям платформ.
- Windows 9.0.0 остаётся доступной отдельным релизом. Сборка Windows после выделения общих компонентов проверена.

macOS-сборка подписана локально (ad-hoc), без нотарификации Apple. Сетевые протоколы проверены эмуляторами, BLE — форматами пакетов; совместимость аппаратных ревизий требует проверки на устройствах.

## 9.0.0

- Название RGBroom, собственная иконка и генератор ярлыка рабочего стола.
- Нативное приложение Windows на .NET 10 / WPF с пятью отдельными вкладками режимов.
- Постоянный цвет, плавные переходы, цветомузыка, частотный спектр и фон по выбранному дисплею.
- Четыре стиля реакции на музыку, разноцветный стробоскоп с мгновенным включением яркости, трёхполосная чувствительность и выбор выхода звука.
- Одновременное управление несколькими контроллерами, проверка связи и автоматическое переподключение.
- Wi-Fi: Magic Home, WLED, Yeelight LAN и Tuya LAN 3.3 / 3.4 / 3.5.
- Bluetooth LE: профили ELK-BLEDOM / ELK-BLEDDM и Triones / LED BLE.
- Защита Tuya local_key через Windows DPAPI.
- Функциональные проверки, сетевые эмуляторы и проверка интерфейса перед Release-сборкой.

Поддержка новых протоколов проверена программно. Совместимость конкретных аппаратных ревизий требует проверки на реальных устройствах; ограничения описаны в COMPATIBILITY.md.
