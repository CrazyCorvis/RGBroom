# Изменения

## 9.0.0

- Название RGBroom, собственная иконка и генератор ярлыка рабочего стола.
- Нативное приложение Windows на .NET 10 / WPF с пятью отдельными вкладками режимов.
- Постоянный цвет, плавные переходы, цветомузыка, частотный спектр и фон по выбранному дисплею.
- Четыре стиля реакции на музыку, разноцветный стробоскоп с мгновенным включением яркости, трёхполосная чувствительность и выбор выхода звука.
- Одновременное управление несколькими контроллерами, проверка связи и автоматическое переподключение.
- Wi-Fi: Magic Home, WLED, Yeelight LAN и Tuya LAN 3.3 / 3.4 / 3.5.
- Bluetooth LE: профили ELK-BLEDOM / ELK-BLEDDM и Triones / LED BLE.
- Защита Tuya local_key через Windows DPAPI.
- Функциональные проверки, сетевые эмуляторы и проверка интерфейса перед Release-сборкой.

Поддержка новых протоколов проверена программно. Совместимость конкретных аппаратных ревизий требует проверки на реальных устройствах; ограничения описаны в COMPATIBILITY.md.
