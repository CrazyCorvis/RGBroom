# Участие в RGBroom

Для разработки нужны Windows и .NET SDK 10. Код приложения — в `Source/`; запускайте `Source/build.ps1`, чтобы проверить Debug перед сборкой Release.

## Сообщить об ошибке

Укажите версию RGBroom и Windows, режим, ожидаемое и фактическое поведение, шаги воспроизведения. Для контроллера добавьте модель, название мобильного приложения, версию прошивки и выбранный протокол. Для BLE полезны рекламируемое имя и UUID сервиса/характеристики.

Не прикладывайте local_key, токены, файлы настроек или полный дамп трафика с секретами. Перед отправкой журнала удалите личные сведения и сетевые адреса.

## Поддержка оборудования

Одна модель может иметь несколько аппаратных ревизий. Подтверждение совместимости должно включать точную ревизию, обнаружение, цвет, яркость, питание и восстановление после отключения. Для цветомузыки проверьте длительное воспроизведение и частые изменения цвета. Результат проверки на эмуляторе отмечайте отдельно от проверки на устройстве.

## Изменения кода

Опишите проблему и итоговое поведение в pull request. Для изменений протоколов добавляйте проверки пакетов или сетевого обмена. Выполните функциональные и интерфейсные проверки до публикации сборки; укажите, было ли доступно реальное устройство.
