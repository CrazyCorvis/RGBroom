## RGBroom 9.1.0 для macOS

Первая версия RGBroom для Mac: управление RGB-подсветкой по Wi-Fi и Bluetooth с нативным интерфейсом SwiftUI.

### Что входит

- Пять режимов: **цвет, плавный переход, цветомузыка, спектр и фон по экрану**.
- Системный дизайн macOS 27: боковая панель, Liquid Glass, меню, SF Symbols, светлая/тёмная тема и горячие клавиши. На старых системах используется их стандартное оформление.
- Wi-Fi: **Magic Home / LEDENET, WLED, Yeelight LAN, Tuya LAN 3.3 / 3.4 / 3.5**.
- Bluetooth LE: **ELK-BLEDOM / ELK-BLEDDM и Triones / LED BLE** через CoreBluetooth.
- Системный звук и изображение дисплея через ScreenCaptureKit; обработка локально, без записи аудио и скриншотов.
- Несколько контроллеров одновременно, проверка связи и переподключение; ключи Tuya в Keychain.

### Скачать и установить

**RGBroom-macOS-arm64.zip** — для Mac с **Apple Silicon (M1 и новее)**, **macOS 14+**. Среда .NET включена, отдельно устанавливать её не нужно. Готовой Intel-сборки в этом релизе нет.

1. Скачайте и распакуйте архив.
2. Перенесите **RGBroom.app** в **Программы** и запустите.
3. Добавьте контроллеры в одноимённом разделе и нажмите **Подключить** (`⌘K`).
4. Выберите режим (`⌘1`–`⌘5`); питание — `⌘P`, настройки — `⌘,`.

Сборка имеет **ad-hoc подпись**, без Developer ID и нотарификации Apple. Если Gatekeeper блокирует первый запуск, проверьте источник скачивания и откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Отключать защиту macOS целиком не требуется.

### Разрешения и отличия от Windows

- Для контроллеров разрешите локальную сеть и/или Bluetooth по запросу системы.
- Для цветомузыки, спектра и фона разрешите **запись экрана и системного аудио**; после изменения разрешения может потребоваться перезапуск приложения.
- Анализируется общий системный звук, без выбора отдельного выхода Windows/WASAPI.
- BLE использует UUID этого Mac: устройства нужно обнаружить заново, MAC-адреса из Windows не подходят.
- Ключи Tuya из Windows DPAPI нужно ввести заново. Для отдельных ELK-ревизий доступен переключатель альтернативных пакетов (handle 13).

Настройки: `~/Library/Application Support/RGBroom/settings.json`. Личные настройки и ключи не включены в архив.

### Проверки

На Mac прошли тесты эффектов и FFT, переподключения, сетевых эмуляторов Magic Home/WLED/Yeelight, зашифрованных сеансов Tuya и Keychain. Проверены запуск SwiftUI и локальная подпись приложения; Windows-проект также собирается. Совместимость всех аппаратных ревизий, особенно BLE/Tuya, не заявляется как проверенная на реальных устройствах.
