## RGBroom 9.1.1 для macOS

- Добавлено меню **Источник звука → Аудиовыход** в цветомузыке и спектре вместо статической подписи.
- Захват выбранного выхода через Core Audio на macOS 14.2+; общий системный звук остаётся доступен.
- Выбор сохраняется отдельно для двух музыкальных режимов. Добавлена кнопка обновления устройств.
- Отключённый выход отображается как недоступный; приложение не переключает источник автоматически.
- Добавлены проверки нативных аудиобуферов и переключения источника в движке.

### Скачать и установить

**RGBroom-macOS-arm64.zip** — Apple Silicon (M1 и новее), **macOS 14+**, .NET включён. Выбор отдельного аудиовыхода требует **macOS 14.2+**; общий системный звук доступен и на macOS 14.0–14.1.

Распакуйте архив, перенесите **RGBroom.app** в **Программы** и откройте **Цветомузыка → Источник звука → Аудиовыход**. Выбор определяет источник анализа и не переключает системное устройство воспроизведения. После подключения наушников или HDMI нажмите **Обновить устройства**. Настройки и контроллеры сохраняются при обновлении.

Для звука разрешите запись системного аудио, для фона — запись экрана. Сборка имеет ad-hoc подпись, без Developer ID и нотарификации Apple. Если Gatekeeper блокирует первый запуск, проверьте источник скачивания и используйте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

### Проверки и ограничения

Пройдены тесты обработки моно/стерео/многоканальных буферов, переключения источников и общих эффектов/протоколов. В интерфейсе проверены раскрытие списка, выбор и сохранение после перезапуска. Полная проверка реакции реальных ламп ограничена недоступностью контроллеров по сети; совместимость всех аудиоинтерфейсов не заявляется.

`SHA256SUMS-macOS.txt` содержит контрольную сумму архива. Аудио и личные настройки в релиз не включены. Для многоканальных устройств анализируются первые два канала первого выходного потока. При отключении выхода или изменении частоты захват нужно повторно запустить.
